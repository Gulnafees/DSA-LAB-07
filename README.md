# DSA-LAB-07

CS-250 Data Structures and Algorithms - Lab 7 (Binary Trees), written in C++.

`Task1.cpp` covers the lab tasks in one program:

- build a binary tree from a string such as `a(b(d,e),c(,f(g,)))`
- validate the tree string without building the tree
- preorder (recursive), inorder (using a stack) and postorder (using two stacks) traversals
- height and depth of each node
- binary search tree insertion and sorted inorder output

## Build and run

```bash
g++ Task1.cpp -o task1
./task1
```
